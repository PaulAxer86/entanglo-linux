# Protocol — see repo root

This is intentionally not a duplicate copy. The authoritative spec is
[`../PROTOCOL.md`](../PROTOCOL.md) at the repo root; keeping a second
copy here would just drift out of sync the first time either changes.

If a future packaging step needs the spec bundled inside a built
artifact (e.g. shipped in a `.deb`'s doc directory), generate it from
the root file at build time rather than hand-maintaining a fork.
